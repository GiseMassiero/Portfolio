Proyectos

NomaPay

Billetera digital multi-moneda con identidad fintech argentina: alias, CBU, KYC, suscripciones y panel de admin. Hice el backend en un equipo de 2. Express · TypeScript · PostgreSQL · Railway · JWT · AWS SES · Gemini · Vitest +

Qué resuelve

Comprar, vender, intercambiar y transferir entre monedas con tasas reales (ExchangeRate-API), con confirmación por email de cada transacción. Todo simulado, sin dinero real.

Decisiones técnicas

  • Modelo de datos propio: users, wallets, balances, currencies, transactions, subscriptions.
  • Autenticación con JWT y refresh token.
  • SQL crudo en lugar de ORM, para entender y controlar el esquema.

Calidad y seguridad

  • 169 tests en el backend.
  • Chatbot de soporte con reglas de sistema y filtro de patrones contra prompt injection (español e inglés).

MCP GitHub Agent

MCP Server que le permite a un agente de IA operar GitHub con lenguaje natural: crear repos, issues, commits y listar el contenido. Node.js · TypeScript · MCP · Octokit · Zod · Vitest +

Qué resuelve

Convierte pedidos como “creá un issue en este repo” en llamadas seguras a la API de GitHub, conectado a un IDE con agente (Antigravity).

Decisiones técnicas

  • 5 tools con contrato claro (nombre, descripción y schema) para que el LLM elija bien.
  • Validación de inputs con Zod.
  • Errores diferenciados (validación, API, autenticación, red) con retry ante rate limit.

Calidad

  • Tests con mocks para retry y errores.
  • Probado de punta a punta con MCP Inspector.
  • README con diagrama de arquitectura.
